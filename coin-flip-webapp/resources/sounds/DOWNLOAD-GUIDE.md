## 🛠️ Audio Editing (Optional)

If you need to edit the sounds (trim, convert, adjust volume):

### Using Audacity (Free)

1. **Download Audacity:** https://www.audacityteam.org/
2. **Install LAME encoder** (for MP3 export)
3. **Open sound file:** File → Open
4. **Trim:** Select portion → Ctrl+T
5. **Adjust volume:** Effect → Normalize
6. **Export as MP3:** File → Export → Export as MP3

### Using Online Tools

- **Convert formats:** https://convertio.co/audio-converter/
- **Trim audio:** https://mp3cut.net/
- **Adjust volume:** https://www.mp3louder.com/
